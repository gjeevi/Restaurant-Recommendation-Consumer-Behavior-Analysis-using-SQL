# Restaurant-Recommendation-Consumer-Behavior-Analysis-using-SQL
Developed a relational database project using MySQL to analyze restaurant ratings, customer preferences, and consumer behavior. Implemented SQL concepts including JOINs, Subqueries, CTEs, Window Functions, Views, and Stored Procedures for data analysis and business insights.

This project focuses on analyzing restaurant and consumer data using SQL. The dataset contains information about consumers, restaurants, cuisines, and restaurant ratings. The objective was to design a relational database, perform analytical queries, and generate business insights from customer behavior and restaurant performance.
